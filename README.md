# Nafis 3D - Скульптинг для пластических хирургов

## 🌟 Описание
Веб-приложение для 3D скульптинга, разработанное специально для пластических хирургов.

## 🚀 Как использовать
1. Откройте сайт
2. Загрузите OBJ файл
3. Загрузите MTL и текстуру (если есть)
4. Кликните по модели для выделения области
5. Используйте инструменты: Сгладить, Вытянуть, Вдавить, Выровнять, Надуть, Сузить

## 🔧 Технологии
- Three.js
- JavaScript
- HTML/CSS
